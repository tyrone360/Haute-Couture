# Simple Shop Website

## Project Description

This project is a simple online shop website created to display products in a clear and user-friendly way.

The website allows customers to view products, check prices, see discounts, and find information about the shop.

## Website Pages

- **Home** – Introduces the shop and its main features.
- **About** – Provides information about the business.
- **Products** – Displays the products available in the shop.
- **Contact** – Provides contact information for customers.

## Technologies Used
- HTML
- CSS

## Main Features

- Simple navigation menu
- Product cards
- Product prices and discounts
- Responsive design
- Contact section
- About section
- Clean and simple layout

## How to Run the Website

1. Download or copy the project folder.
2. Open the folder in **Visual Studio Code**.
3. Make sure all HTML and CSS files are in the correct folders.
4. Open `index.html`.
5. Right-click and select **Open with Live Server**, or open the HTML file directly in a web browser.

## Purpose of the Project

The purpose of this project is to demonstrate basic web development skills using HTML and CSS. It also shows how a simple online shop can be designed for customers.
